# Harness 桌面控制器 说明书

## 这是什么

`Harness 桌面控制器` 是一个运行在 Windows 桌面上的独立小工具，用来：

- **启动** DeepSeek Harness
- **关闭** DeepSeek Harness
- **重启** DeepSeek Harness

它使用和风界面风格：和纸白底色、绀青与洗朱主色、抹茶绿与山吹茶辅助色，并加入竹、枫叶、红日、破墨线、朱砂锚点、茣蓙目纹理等日式元素。

## 为什么可以脱离 Harness 独立启动

它**不是**一个跑在 Harness 网页里的插件，而是 Harness 的**桌面伴侣程序**。

- 它不依赖 Harness 自身运行。
- 即使 Harness 当前没有启动，你也可以从桌面图标直接打开控制器。
- 打开后点击“启动 Harness”即可拉起 Harness 服务。

## 界面说明

窗口启动后会显示在桌面并出现在任务栏，可固定到任务栏。

界面包含：

- **状态**：显示 Harness 当前是否运行。
- **启动 Harness**：启动 Harness 服务；如果服务已运行，会提示已在运行。
- **关闭 Harness**：结束 Harness 相关进程树；操作前会弹出确认。
- **重启 Harness**：先关闭，再重新启动 Harness。
- **运行日志**：显示最近的操作记录和状态变化。

> 关闭控制器窗口不会停止已启动的 Harness；Harness 会继续在后台运行。

## 快速开始

### 1. 准备环境

- Windows 系统
- Python 3（自带 Tkinter）
- DeepSeek Harness 的 `dsh` 命令可用

### 2. 创建桌面图标

在 PowerShell 中执行：

```powershell
cd D:\develop\WorkSpeace\TEMP\time_line_mind\desktop-control
powershell -ExecutionPolicy Bypass -File .\install_desktop_shortcut.ps1
```

脚本会自动找到 `pythonw.exe`，并在桌面创建“Harness 控制器.lnk”快捷方式。

### 3. 启动控制器

双击桌面上的“Harness 控制器”图标，或运行：

```powershell
pythonw.exe .\harness_control.py
```

### 4. 启动 Harness

在控制器窗口中点击“启动 Harness”。

- 默认启动命令是 `dsh --profile web`
- 默认访问地址是 `http://127.0.0.1:3080`
- 启动成功后会自动打开浏览器

## 配置说明

配置文件为同目录下的 `config.json`：

| 字段 | 说明 |
|---|---|
| `name` | 显示名称 |
| `command` | 启动 Harness 的命令 |
| `url` | 启动后自动打开的地址，也是状态检测地址 |
| `working_dir` | 启动命令的工作目录；`null` 表示使用当前目录 |
| `open_browser` | 启动成功后是否自动打开浏览器 |
| `port` | 状态检测端口 |
| `pid_file` | PID 文件位置 |
| `log_file` | 日志文件位置 |

示例：

```json
{
  "name": "DeepSeek Harness",
  "command": ["dsh", "--profile", "web"],
  "url": "http://127.0.0.1:3080",
  "working_dir": null,
  "open_browser": true,
  "port": 3080,
  "pid_file": "state/harness.pid",
  "log_file": "state/harness.log"
}
```

如果 `dsh` 不在 PATH 中，程序会自动在 npm/npx 缓存目录里查找。也可以把 `command` 改成完整路径或 `pnpm dsh --profile web`。

## 工作原理

### 启动

- 使用 `subprocess.Popen` 以无窗口后台方式启动 `dsh --profile web`（`CREATE_NO_WINDOW`），不会弹出 CMD 窗口。
- 将 PID 写入 `state/harness.pid`。
- 关闭控制器窗口不会杀掉 Harness。

### 关闭

- 优先读取 PID 文件。
- 通过 `netstat` 查找监听端口对应的 PID。
- 通过 PowerShell 匹配 `dsh ... web` 命令行进程。
- 使用 `taskkill /PID <pid> /T /F` 结束整个进程树。

### 重启

- 先执行关闭流程并等待端口释放。
- 再执行启动流程。

## 注意事项

- 关闭 Harness 使用强制结束进程树（`taskkill /T /F`），可能会丢失未保存的会话数据。
- 请先确认没有正在执行的重要任务，再点击“关闭 Harness”。
- 如果 Harness 是手动在另一个终端启动的，控制器同样可以通过端口/PID 检测到并关闭它。
- 如果端口不是默认的 `3080`，请同步修改 `config.json` 中的 `url` 和 `port`。

## 常见问题

### 双击桌面图标没有反应

- 确认 Python 已安装且 `pythonw.exe` 可用。
- 重新运行 `install_desktop_shortcut.ps1` 创建快捷方式。
- 也可以直接运行 `run_controller.bat` 或 `pythonw.exe .\harness_control.py`。

### 提示找不到 dsh

- 确认 DeepSeek Harness 已安装，且 `dsh` 命令可在终端中执行。
- 在 `config.json` 的 `command` 中填写 `dsh` 的完整路径。

### 关闭后端口仍然被占用

- 可能是 Harness 的子进程没有完全退出。
- 在任务管理器中结束残留的 `node.exe` / `cmd.exe` 进程，或重启电脑。
